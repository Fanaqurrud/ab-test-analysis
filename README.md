# Анализ механики оплаты и сегментация клиентов

## О проекте

Проект посвящён оценке новой механики оплаты в образовательном продукте и подготовке SQL-логики для сегментации клиентов.

## Цель

Проверить влияние новой механики оплаты на ключевые продуктовые метрики и подготовить SQL-запрос для выделения клиентских сегментов.

## Стек

- Python
- pandas
- SciPy
- Matplotlib
- SQL
- PostgreSQL
- Jupyter Notebook

## Что сделал

- Объединил данные из 4 CSV-файлов.
- Рассчитал ключевые метрики для **8 341 активного пользователя**.
- Сравнил показатели контрольной и тестовой групп.
- Проверил статистическую значимость изменений.
- Выявил **149 плательщиков**, отсутствующих в списке активных пользователей.
- Написал SQL-запрос для выделения **4 сегментов клиентов**.
- Подготовил функции для автоматического обновления метрик и построения графиков.

## Результат

После внедрения новой механики оплаты наблюдался рост ARPU на **22,62%**, однако статистически значимого подтверждения улучшения получить не удалось.

По итогам анализа рекомендовано **отложить массовый запуск новой механики** до получения дополнительных данных.

## Описание файлов

- `ab_test_analysis.ipynb` — основной блокнот с обработкой данных, расчётом метрик и статистическим анализом;
- `data/Проект_2_active_studs.csv` — данные об активных пользователях;
- `data/Проект_2_checks.csv` — данные об оплатах;
- `data/Проект_2_group_add.csv` — дополнительные данные о распределении пользователей по группам;
- `data/Проект_2_groups.csv` — данные о принадлежности пользователей к экспериментальным группам.

## Запуск

2. Установить необходимые библиотеки.
